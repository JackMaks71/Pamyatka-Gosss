Тёмная современная карточка-памятка с Уголовным кодексом и процессуалкой.

---

## Как получить ссылку на сайт (пошагово)

### Шаг 1. Скачай эту папку
Скачай всю папку `uk-pamyatka` целиком (в ней уже лежат все нужные файлы).

### Шаг 2. Создай репозиторий на GitHub
1. Зайди на сайт: [https://github.com/new](https://github.com/new)
2. В поле **Repository name** напиши, например: `uk-pamyatka`
3. Поставь репозиторий в **Public**
4. **Ничего больше не отмечай** (не добавляй README, .gitignore и License)
5. Нажми зелёную кнопку **Create repository**

### Шаг 3. Залей файлы
1. На странице нового репозитория нажми синюю ссылку  
   **uploading an existing file**
2. Перетащи **все файлы** из папки `uk-pamyatka` в окно:
   - `index.html`
   - `README.md`
   - `.gitignore`
3. Внизу нажми **Commit changes**

### Шаг 4. Включи GitHub Pages (чтобы появилась ссылка)
1. В репозитории нажми вкладку **Settings**
2. В левом меню найди и нажми **Pages**
3. В разделе **Build and deployment** → **Source** выбери:
   - Branch: **main**
   - Folder: **/ (root)**
4. Нажми **Save**

### Шаг 5. Получи ссылку
Подожди 1–2 минуты и обнови страницу.  
Появится адрес вида:

```
https://ТВОЙ_НИК.github.io/uk-pamyatka/
```

Именно эту ссылку можно отправлять другим.
